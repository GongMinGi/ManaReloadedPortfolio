## 📜 게임 소개
<마나 리로디드>는 판타지 탑 뷰 슈팅게임입니다. 당신은 구닥다리라고 멸시받는 원소마법의 수행자로서, 원소마법의 권위를 되살리고, 부와 명예를 쟁취하기 위해 적진 한복판으로 뛰어듭니다.  
사방에서 몰려오는 평화롭고 사악하기 그지없는 마족들을 모두 처치하여, 원소 마법의 마력과 플레이어의 실력이 일으키는 시너지를 한껏 끌어올려 보십시오.
